# Привычки — Telegram Mini App

Рабочий MVP: планировщик дня + трекер привычек (бросить/добавить) + бег/велосипед с реальным GPS-трекингом. Тёмная и светлая тема — как в макете, который мы утвердили. Тема подхватывается автоматически из Telegram, акцентный цвет и всё остальное уже зашито в код.

Состоит из двух частей:

- **`webapp/`** — сам мини-апп (React + Vite). Это статический сайт, который открывается внутри Telegram.
- **`bot/`** — маленький бот на Telegraf, который просто открывает этот сайт как мини-апп (кнопка в меню рядом с полем ввода).

Сейчас всё хранится в `localStorage` телефона — то есть после первого открытия данные никуда не потеряются, но между разными устройствами не синхронизируются. Это осознанное упрощение для MVP, синхронизация через бэкенд — следующий шаг (см. низ файла).

## Что уже работает по-настоящему (не бутафория)

- Чек-ины по расписанию дня, счётчик стаканов воды, отметки по привычкам, кнопка «Сорвался» со сбросом счётчика и сохранением рекорда — всё сохраняется между открытиями приложения.
- Голосовой ввод задачи на экране «Сегодня» — реальное распознавание речи через Web Speech API браузера (диктуешь — текст сам попадает в форму, остаётся поправить время и подтвердить).
- Пробежка/велопрогулка — по-настоящему трекается через GPS телефона (`geolocation.watchPosition`), считается дистанция, темп и калории, и после нажатия «Остановить» сохраняется в историю.
- Тема (светлая/тёмная/как в Telegram) переключается в Профиле и реально применяется по всему приложению.

## Что нужно знать про ограничения (честно, чтобы не удивляться)

- **GPS работает только пока приложение открыто на экране.** Если заблокировать телефон посреди пробежки — трекинг остановится. Это ограничение самого Telegram Mini App (он живёт в WebView и не работает в фоне), не баг. Обход обсуждали раньше — синхронизация с Apple Health / Google Fit постфактум, это уже отдельная фаза с нативным помощником.
- **Голосовой ввод (Web Speech API) надёжно работает в Chrome/Android.** В Telegram на iOS поддержка распознавания речи в WebView исторически нестабильна — если на iPhone кнопка не сработает, приложение само предложит ввести текст вручную (это заложено как запасной вариант, а не поломка).
- **Action Button и двойной тап по корпусу iPhone** — как и обсуждали, это нельзя вызвать напрямую из мини-аппа. Рабочий обход — связка через приложение iOS «Команды» (Shortcuts), это отдельный небольшой шаг, сейчас не входит в этот MVP.
- Данные живут в `localStorage` на конкретном телефоне. Если поставить приложение на другое устройство — данные не подтянутся. Настоящая синхронизация требует бэкенда с базой данных (см. «Что дальше»).

## Как запустить и посмотреть локально (без Telegram)

Нужен установленный Node.js (18+).

```bash
cd webapp
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173` — открой его в браузере на телефоне или в эмуляторе мобильного экрана в DevTools. Вне Telegram голосовой помощник и тема будут работать через обычные браузерные API (а не через Telegram SDK), это нормально для разработки.

## Как выложить фронтенд в интернет (нужен https-адрес для бота)

Раз ты уже деплоил ABUEX на GitHub Pages — тот же путь подойдёт и здесь:

```bash
cd webapp
git init                      # если папка ещё не в своём репозитории
git add .
git commit -m "Первая версия мини-аппа"
git remote add origin https://github.com/<твой-юзернейм>/<репозиторий>.git
git push -u origin main

npm run deploy                 # соберёт проект и запушит его в ветку gh-pages
```

После этого зайди в настройки репозитория на GitHub → Pages → убедись, что источник — ветка `gh-pages`. Сайт появится по адресу `https://<твой-юзернейм>.github.io/<репозиторий>/` — это и есть `WEBAPP_URL` для следующего шага.

(Подойдёт и Vercel/Netlify, если удобнее — просто перетащить папку `webapp` в их интерфейс, тоже бесплатно и тоже сразу даёт https-адрес.)

## Как создать самого бота

1. Открой в Telegram **@BotFather**.
2. Команда `/newbot` → придумай имя и юзернейм (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456:ABC-DEF...`. Это `BOT_TOKEN`.

## Как запустить бота и подключить к нему мини-апп

```bash
cd bot
npm install
cp .env.example .env
```

Открой `.env` и впиши:

```
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://твой-адрес-с-предыдущего-шага
```

Запусти бота:

```bash
npm start
```

Дальше открой своего бота в Telegram, нажми **Start** — придёт сообщение с кнопкой «Открыть приложение», плюс рядом с полем ввода появится постоянная кнопка меню «Привычки». Это и есть готовый к работе мини-апп.

Пока бот запущен только на твоём компьютере (`npm start`), он работает только пока запущен процесс. Чтобы он работал постоянно — его тоже нужно куда-то задеплоить (Railway, Render, обычный VPS — на любой из них можно один раз залить папку `bot/` и запустить `npm start` там).

## Что дальше (из плана, который мы обсуждали)

- Бэкенд с базой данных (Postgres/Supabase) — чтобы данные не терялись при смене телефона и синхронизировались между устройствами.
- Настоящий голосовой ввод через бота: голосовое сообщение → Whisper → Claude API разбирает на структурированные задачи (сейчас это делает браузерный Web Speech API, без ИИ-разбора времени/повторов).
- Мост через iOS Shortcuts для Action Button / двойного тапа.
- Постфактум-синхронизация с Apple Health / Google Fit для трекинга в фоне.
